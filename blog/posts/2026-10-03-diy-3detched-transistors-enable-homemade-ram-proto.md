Dr.Semiconductor streamed a live demo 15 hours ago that walks through a shed‑etch technique for fabricating 3‑D transistors used in a homemade RAM cell. The video, titled *Shed Etching 3D Transistors for Homemade RAM*, has already gathered nearly 20 K views on YouTube.[^1]

## The shed‑etch technique in a nutshell
The presenter uses a simple chemical etch—sometimes called “shed etching”—to carve vertical structures out of a silicon wafer. By stacking these structures, he creates a three‑dimensional transistor geometry that can be wired into a basic memory array. The process is demonstrated on a benchtop setup rather than a clean‑room environment.

## What the prototype actually shows
The video’s core achievement is a proof‑of‑concept: a functional transistor stack that can store a bit of data, essentially a single‑cell RAM element. No performance metrics or production‑ready specifications are provided; the focus is on the feasibility of building a memory cell from scratch with minimal equipment.

## Limits and what the video doesn’t cover
The description does not list component costs, yield rates, or scalability paths, so it’s unclear how the approach would translate to larger memory arrays. Additionally, the channel page does not provide schematics or detailed process parameters, leaving the replication effort up to the viewer’s interpretation.

**When to try it** – If your startup’s hardware team enjoys low‑cost silicon experiments and you have access to basic etching supplies, the video offers a hands‑on reference for a DIY memory cell. Keep expectations realistic: the demonstration is a single‑cell prototype, not a production‑grade RAM module.
