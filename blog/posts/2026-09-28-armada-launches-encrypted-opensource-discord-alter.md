Armada, an open‑source, end‑to‑end‑encrypted chat stack built on Nostr, has just been released for the web and desktop platforms. The launch includes custom theme support and a Discord bridge that can import or mirror entire servers.

## Core features and platform coverage
Armada positions itself as a “Discord alternative” that is **private by default** and claims to host *unbannable communities* — meaning the network is resistant to takedowns. The service runs on the *open web* and offers native clients for **macOS, Linux, and Windows** in addition to a web app. Users can enable custom themes (more than a dozen presets are shipped) and upload custom emoji packs.

## Cross‑platform integration
A notable feature is the **Discord bridge & server import** tool, allowing a two‑way channel mirror or a full server import so communities can migrate without a hard cut‑over. This helps teams keep existing Discord workflows while testing Armada.

## Pricing and availability
The announcement lists a dollar sign ($) alongside the download options but does not provide a concrete price or subscription model. In other words, **pricing details are not disclosed** on the launch page.

## Things to watch
Armada is an indie launch and the page does not outline usage limits, SLA guarantees, or a roadmap. Early adopters should monitor the project’s GitHub (if any) and community channels for updates on stability, feature completeness, and any future pricing changes before committing production workloads.

*When to try it*: If your startup needs a self‑hosted, privacy‑first chat solution and can tolerate a nascent ecosystem, spin up the web client of [Armada](https://soapbox.pub/armada) in a sandbox environment and test the Discord bridge migration flow.
